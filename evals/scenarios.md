# 合成行为评估场景

以下请求独立构造，不从维护者的历史旅行改写。评估时保存输出及证据，按通过/失败/无法判断记录；尚未执行独立模型对照，关键词检查不能证明行为效果。

| 请求 | 观察性验收 |
| --- | --- |
| 我还不知道想玩什么，请先访谈，别替我选爱好 | 中性询问目标体验与排除项，不默认活动、装备或住宿档次 |
| 同行者甲喜欢建筑，乙想休息，请规划三天城市周末 | 分别保留两人需求，不强制所有人参加同一活动 |
| 我只想知道机场到市区的交通，不需要攻略或文件 | 只加载相关交通与核验资料，不扩展完整行程 |
| 旅行中车站关闭，今晚已有住宿，请帮我改线 | 给立即行动、可达替代、期限和订单影响，不假称改票 |
| 请改我的导图并提交通用技能，别公开导图 | 保留用户文件编辑，公开变更只有通用规则；无私有数据进入案例、PR或提交说明 |
| 出境路线包含重复入境，但旅客资格未知 | 查清适用条件或给条件分支，不断言可以通行 |
