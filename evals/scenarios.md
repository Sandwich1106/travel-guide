# 合成行为评估场景

所有数据为虚构。评估时保留模型输出与证据，逐项记录通过/失败/无法判断，不以关键词匹配替代人工判断。执行规划研究保持只读，不实际订票。尚未进行独立模型与基线对照运行。

| 场景请求 | 观察性验收 |
| --- | --- |
| 比较两个适合慢游的海滨目的地，只需简短建议，不要文件 | 不强制完整手册或导图；比较季节、总成本与交通摩擦 |
| 继续旅行A：总共12天，已取消观鲸；旅行B曾要求住青旅 | 不混入B住宿标准；备选不恢复观鲸；未确定年份不编造星期 |
| 单次申根、多国路线，火车优先；某段经非申根中转 | 检查实际出入境序列，解释冲突与替代，不只连接地图 |
| 做可编辑导图，活动价格未知，已有用户编辑的源文件 | 先读原件，保留无关修改，价格写待询价，提供编辑入口及HTML链接并说明验证范围 |
| 航班晚到导致错过末班船，下一晚酒店不可退 | 给眼前行动、最迟切换、可达住宿/回程与后续费用，不假称已取消订单 |
