## 可复现合成案例验收

运行 `python3 scripts/check_example.py`，从完全虚构的输入生成 Markdown、HTML 和 JSON 报告。消费2120 TEST，备用300，资金合计2420，上限3000，余量580。首轮输入上限2400触发预算失败，修订虚构需求上限后重新运行；这是输入修订，不是声称原预算可行。

覆盖：日序与住宿夜数、逐项费用、时序与预约到达余量、证据引用、未预订状态、关闭后的替代时段与预算。七个故障注入均检出：重叠、超预算、缺住宿、无效证据、预约晚到、备选波及后续、假称已订。

案例为不跨境城市短途，不触发国际签证、专项活动或导图编辑器模块；这些不列为已通过。真实世界核验与独立模型效果评估仍不在此报告的通过范围内。不能通过挑选简单案例宣称整个旅行 Skill 全面验收。
