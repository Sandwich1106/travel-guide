| 一手页面 | 本轮观察与采纳 | 不外推的内容 |
| --- | --- | --- |
| [Rick Steves研究旅行](https://www.ricksteves.com/travel-tips/trip-planning/researching-your-trip) | 跨来源研究要识别错误与利益关系，来源多不等于可靠 | 不给指南或博主永久权威地位 |
| [Seat61购票](https://www.seat61.com/european-train-tickets-online.htm) | 同一段铁路的销售渠道、票种与取票方式会改变价格及可用性；放票前可先设计路线 | 不复制示例票价作为未来报价 |
| [Japan Guide两周路线](https://www.japan-guide.com/e/e2400_best.html) | 逐日城市与夜宿可作为骨架，并审查其较快节奏是否适合本次旅客 | 不把现成路线当统一标准 |
| [Japan Guide通票计算器](https://www.japan-guide.com/railpass/) | 按实际区段计算通票，补查订位和未覆盖段 | 计算器结果不等于每趟都有座位 |
| [小气少年首访规划](https://nicklee.tw/3128/first-self-tour/) · [换乘](https://nicklee.tw/2152/japan-transport-transfer/) | 中文攻略应深入到换乘与首次操作，而非只列景点名称 | 年份、票种及运营信息仍查原经营方 |
| [来一球冬季活动案例](https://gototravel.tw/shikaribetsuko-ice-village/) | 把活动季节、交通、营业和住宿放在同一决策中研究 | 活动日期回到主办方确认，不继承作者推荐为用户兴趣 |
| [Intrepid条款](https://www.intrepidtravel.com/en/standard-booking-conditions) | 区分通用合同与具体产品条款，取消和包含项需要对应商品 | 不套用团队服务为自由行保障 |
| [National Rail放票](https://www.nationalrail.co.uk/travel-information/advance-booking-dates/) | 按运营商/班次核对预售窗口，远期未开售不阻塞攻略完成 | 未开售不代表线路不存在或停运 |
| [INAH奇琴伊察](https://lugares.inah.gob.mx/en/node/5663) | 官方也可能列基础费以外的地方收费，预算需查完整价格结构 | 不把单一收费项目当总价 |
| [KDE Itinerary](https://apps.kde.org/itinerary/) | 行程订单与途中信息应有关联，隐私与本地处理需要单独考虑 | 功能介绍不是本项目已经实现相同软件能力 |

## 小红书与中文平台

用户推荐小红书是重要研究方向，不等于任何笔记天然高于或低于携程。按内容质量选：明确实际旅行日期、路线、门到门耗时、房型/产品、价格单位、失败经验及评论纠错。首页、登录页、镜像、营销报告和第三方摘录不能冒充已读实测。

本轮小红书入口跳转登录，尚未读到原帖正文，计0篇已读笔记。穷游、马蜂窝、背包客栈及BringYou存在渠道间访问差异；中文独立作者与KKday/Klook等入口补充发现线索，商业平台需标记产品推广动机。下一次有可读原帖时，以逐篇记录更新目录，不伪造笔记、作者或点赞数。
