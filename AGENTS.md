# Travel Guide / 深度旅游攻略

Use [travel-guide](.agents/skills/travel-guide/SKILL.md) to create, audit, or revise travel plans. Match the user's requested language or the language of their request. Add or update itinerary files only when the user asks to save them.

用户要求制作、审查或改动旅行方案时，使用上述 Skill。按本次旅客条件规划。用户要求保存时再新增或更新攻略文件。
