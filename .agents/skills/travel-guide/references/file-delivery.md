# File delivery and revisions / 文件交付与原件更新

[简体中文](#简体中文) · [English](#english)

## 简体中文

按用户指定交付 PDF、Excel（.xlsx）、思维导图或所需组合。未指定且只需对话答复时用 Markdown。适合打印、离线看或分享用 PDF；需要改行程、比价、记账、筛选用 Excel。只有当格式会改变结果且无法推断时才询问。使用当前环境提供的 PDF、表格制作与验证工具；可用时遵循对应文件技能。交付前确保链接指向实际生成的文件。

- **PDF**：先生成结构化内容，再排版。包含一页摘要、逐日行程、逐段交通、预算、预约和来源，按需求附手机随身页。保留可选中文字、中文字体和可点链接，渲染检查分页、表格、字体和内容截断。为后续更新保留可编辑源或重建所需的结构化内容，作为工作资料；用户只要求 PDF 时仅交付 PDF。
- **Excel**：用「总览」「逐日行程」「交通」「预算」「预订与复核」「来源」等适用工作表。金额、日期、时间和状态用合适的数据类型，预算用可核算的公式。区分原币、换算金额、人均与两人/全团、已付与待付。检查公式结果、引用、日期顺序、筛选与导航链接；如与 PDF 一起交付，使用同一份行程数据。
- **可选思维导图**：仅在用户要求或选定该形式时生成，也可作为 PDF 或 Excel 的配套视图。默认用竖向目的地／阶段主干，子气泡向右，每个日期独立。日期下写交通时间与站点、住宿、活动、用餐、费用、预约和备选，按实际需要取舍。签证、SIM、支付、防宰客、总预算、健康与装备等跨天事项独立成分支。节点摘要直接显示关键数据，较长内容可展开；区分已确认、估算、班表线索与待核验。用来源链接和跨节点依赖说明关键衔接，例如潜水后飞行或晚到影响次日早船。按完整攻略核对用户逐项要求与最新修订，避免因转成导图遗漏条件。优先提供当前环境可交互查看的形式，用户要打印时可交付静态版。更新时保留原导图和同步范围。
- **收到修改建议**：按已有对话、明确路径或当前文件确认目标。目标明确且用户要求修改时，默认更新同一路径和文件名；指定另存才生成新副本。Excel 保留用户的手填金额、备注、公式和样式，仅改动相关区域及其依赖。PDF 优先改源再渲染替换；若只有 PDF，先提取并核对已有内容，能保留版式和内容才覆盖。有无法可靠复原的部分时，说明影响并交付可审阅的更新稿，保留原件。
- **同步与验证**：修改活动或日期时，联动交通、住宿夜数、预算、付款及退改、预约、来源状态和随身页。同一行程有 PDF、Excel 或思维导图时，按用户指定范围更新；同时在范围内的版本使用同一份日期、状态和金额。覆盖前先在临时位置生成或保留可恢复版本，验证可读且计算正确后再替换。最后给同一文件的链接、简短变更摘要与仍需确认的事项。

## English

Deliver PDF, Excel (.xlsx), a mind map, or a requested combination. Use Markdown for an ordinary chat response when no file is requested. Use PDF for reading offline, printing or sharing, and Excel for itinerary edits, quote comparisons, expense tracking and filters. Ask about format only when it materially changes the result and cannot be inferred. Use available PDF/spreadsheet tools and follow their format-specific skills when available. Link to the verified output file.

- **PDF**: Build structured content and lay it out. Include a brief, days, transport legs, budget, bookings and sources, plus mobile pages when useful. Preserve selectable text, appropriate Chinese fonts when needed, and clickable links. Render and inspect pagination, tables, font rendering and clipping. Keep editable or reconstructable working content for future revisions. Deliver the PDF alone when that is the requested output.
- **Excel**: Use relevant tabs such as Overview, Daily Plan, Transport, Budget, Bookings and Rechecks, and Sources. Use suitable data types and auditable budget formulas. Separate original and converted currency, party and individual costs, and paid vs. outstanding. Verify formula results, references, dates, filters and links. When delivering both formats, generate from shared itinerary data.
- **Optional mind map**: Generate only when the user requests or selects it, either alone or alongside PDF/Excel. Default to a vertical trunk of destinations or phases, with rightward bubbles for individual dates. Show each day's applicable transport times and stops, lodging, activities, food, costs, bookings and fallbacks. Group trip-wide items such as visas, SIM, payments, fare pitfalls, budget, health and packing on their own branch. Put key details directly in summaries and make longer details expandable where supported. Mark confirmed facts, estimates, schedule leads and pending checks. Link sources and dependencies, such as no-fly windows after diving or an early ferry after a late arrival. Reconcile every explicit requirement and latest correction against the full guide. Prefer an interactive view when supported, or a static print version when requested. Update the same map and respect the requested synchronization scope.
- **Revisions**: Resolve the target using the conversation, stated path or current file. When the file is clear and revision is requested, update the same path and filename by default. Save a separate copy when requested. In Excel preserve user entries, notes, formulas and styling while updating related areas and dependencies. In PDF revise the editable source and re-render when possible. If only a PDF is available, reconstruct and verify its contents and layout before replacing it. If restoration is unreliable, explain the impact, provide a reviewable update, and preserve the original.
- **Reconcile and verify**: Propagate date and activity changes to transport, nights, budget, payment and refund terms, bookings, evidence and mobile pages. Respect the requested scope across PDF, Excel and mind-map versions. Reconcile dates, statuses and costs across all versions in scope. Generate a temporary or recoverable version before replacement and verify readability and calculations. Return the same file link, a short change summary and pending checks.
